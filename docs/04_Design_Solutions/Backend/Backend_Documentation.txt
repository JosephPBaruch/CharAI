CharAI Backend Documentation
---

User Registration
---
Endpoint: POST /register  
Description: Creates a new user account. Validates input and generates a JWT token.  
Request Body:
{
  "username": "string",
  "email": "string",
  "password": "string"
}  
Response:
{
  "token": "JWT_TOKEN",
  "message": "Signup successful"
}  
APIs/Azure Services: Azure SQL Database for storing user data, Azure Active Directory B2C for authentication

User Login
---
Endpoint: POST /login  
Description: Authenticates an existing user and returns a JWT token.  
Request Body:
{
  "email": "string",
  "password": "string"
}  
Response:
{
  "token": "JWT_TOKEN",
  "message": "Login successful"
}  
APIs/Azure Services: Azure SQL Database, Azure Active Directory B2C for authentication

Manual Land Coordinate Entry
---
Endpoint: POST /land-coordinates  
Description: Accepts user-provided coordinates, validates them, and returns GeoJSON data for mapping.  
Request Body:
{
  "coordinates": [
    {"lat": float, "long": float},
    ...
  ]
}  
Response:
{
  "geojson": {...}
}  
APIs/Azure Services: Azure Maps API for validation, Azure Functions for processing coordinates

Land File Upload
---
Endpoint: POST /upload-land  
Description: Uploads .kml or .geojson files to extract field boundaries and returns GeoJSON.  
Request Body: FormData with file attachment (`.kml` or `.geojson`)  
Response:
{
  "geojson": {...},
  "message": "Upload successful"
}  
APIs/Azure Services: Azure Blob Storage for temporary file storage, Azure Functions for GeoJSON extraction

Generate Prescription Map
---
Endpoint: POST /generate-map  
Description: Generates a color-coded prescription map based on field data, soil, slope, moisture, and optional biochar adjustments. Stores map metadata and returns download link.  
Request Body:
{
  "field_coordinates": {...},
  "soil_data": {...},
  "slope_data": {...},
  "moisture_data": {...},
  "biochar_adjustment": "optional"
}  
Response:
{
  "map_url": "https://storage.azure.com/container/map_id.png",
  "metadata": {
    "map_id": "string",
    "date_created": "YYYY-MM-DD"
  }
}  
APIs/Azure Services: Azure Machine Learning for yield prediction engine, Azure Maps for rendering, Azure Blob Storage for storing map files, Azure SQL Database for metadata

Download Map
---
Endpoint: GET /download-map/{id}  
Description: Fetches a generated map file from storage and streams it to the frontend for download.  
Request Params:
- id: string (Map file ID)  
Response: File stream of the map image or .geojson  
Azure Services: Azure Blob Storage for file storage and retrieval

Notes
---
- Authentication: JWT tokens should be sent in the Authorization header for all protected endpoints: Authorization: Bearer <JWT_TOKEN>  
- File Storage: All uploaded files and generated maps are stored in Azure Blob Storage with public or signed access URLs.  
- Geo Processing: Azure Functions or Logic Apps can handle GeoJSON validation and conversion.  
- Yield Prediction: Azure Machine Learning or a custom containerized model deployed on Azure Kubernetes Service can be used to run the predictive model.
