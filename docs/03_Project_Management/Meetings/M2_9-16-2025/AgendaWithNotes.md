## Agenda

### Introduction

### Project Description Overview
- The project is to create a web application that allows farmers (customers) to enter farm boundaries and yield data. The application will produce prescription maps to inform farmers on how to apply Biochar.

### Preliminary Work
- Data has been gathered on soil water retention in the Palouse.

### Questions
1. Why is solving this problem important to your organization/cause?
2. What has been done to solve this problem? Has anything worked?
3. What would success look like?
4. Of all the things you would like to see, which are necessary, and which are stretch goals?
5. What constraints should we be aware of?
6. Describe in detail what the end user would look like.
7. How aware is the end user of this problem? How familiar is the end user with technology?
8. How will this project be evaluated on your end?
9. How often would you like updates or check-ins?
10. How can we access the data necessary to complete this project?
11. What does a use case look like?
12. What are the customer inputs to this application?  
    - Use this answer to create UX mocks.
13. What data is sensitive?  
    - Stored locally? Encrypted?
14. Do we need to use Microsoft Azure, or could we use a different platform?
15. Are there requirements for languages, libraries, or IDEs?
