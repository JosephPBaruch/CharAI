# 9\_15\_2025 - Client Interview Questions



1. Why is solving this problem important to your organization/cause?

2\. What has been done to solve this problem? Has anything worked?

3\. What would success look like?

4\. Of all the things you would like to see, which are necessary, and which are nice to have?

5\. What constraints should we be aware of?

6\. Describe in detail what the end user would look like.

7\. How aware is the end user of this problem? How familiar is the end user with technology?

8\. How will this project be evaluated on your end?

9\. How often would you like updates or check-ins?
